## Related risk requiring a separate decision

- Storyteller input lengths and types can be bounded locally. The 15-second timeout races the AI call without proven cancellation; actual post-timeout quota use and cancellation support need an authorized real-AI check. Storyteller receives a public projection and sends drafts only to host sockets in the reviewed path.
- Room lookup and creation are anonymous by design. The accessible Cloudflare zone query returned `9109: Unauthorized to access requested resource`, so live WAF and rate rules could not be checked. A rate policy needs an account budget and desired invitation behavior; this branch must not guess a production edge rule.
- Complete event-log compaction changes Durable Object persisted state and replay/rollback behavior. Specify retention, history shown to host and dead players, migration and rollback before implementing it.

## Verification and release boundary

Baseline checks: typecheck and build passed; engine (200) and client (54) tests passed. Server test startup and normal `wrangler dev` were blocked by Cloudflare preview authentication error `10000` on the Workers AI binding. An isolated local workerd config with fake Storyteller passed 55/55 Playwright scenarios. See the full review for commands, measured timings, and limitations.

Branch verification after implementation: `npm run typecheck`, `npm run build`, and `git diff --check` passed. `./scripts/test-local.sh` passed **202 engine, 56 client, and 150 server tests** against an isolated local config with the same DO, assets, and metrics bindings but no remote AI preview binding. `npx playwright test --config scripts/review-playwright.config.ts` passed **55/55** against a fresh isolated workerd state with fake Storyteller. `node scripts/review-local.mjs` passed its 20-seat, malformed-message, authority, privacy, and repeat-action probes. The final probe recorded 20 seats after the attempted 21st join, `room_full`, `error:bad_message` for malformed `hello`, and a host-log delta of one for ten identical tentative actions. These are local checks, not production latency or quota measurements.

The `MAFIA_TEST_WRANGLER_CONFIG` override is in `vitest.workers.config.ts`; `scripts/test-local.sh` creates and removes its temporary config. Build first so `dist/client` exists for server asset tests. `scripts/review-local-server.sh` creates a fresh no-AI workerd config and state for browser reruns. This branch has no deployment, live Cloudflare configuration change, or production room test.
